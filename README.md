# 🍺 Tapper - HTML5 Arcade Classic (1983)

A lightweight, dependency-free HTML5/JavaScript remake of the iconic 1983 Bally Midway arcade game **Tapper**. Features a custom arcade cabinet bezel, procedural pixel art, 4-lane mechanics, and retro synthesized Web Audio API sound effects.

🚀 **[Play the Live Demo](https://andrejverity.github.io/tapper/)**

---

## 🕹️ Gameplay & Rules

Keep the patrons happy, collect empty mugs, and grab cash tips before time runs out!

* **Serve Drinks:** Stand at the right end of a lane next to the tap handle and press `Space` to launch a beer.
* **Catch Empty Mugs:** Patrons slide empty mugs back down the counter after drinking. Stand in their path to catch them before they fall off the end.
* **Collect Tips:** Grab cash left on the counters for bonus points.
* **Lives:** You lose a life if a full mug falls off the left end, an empty mug smashes on the right end, or a customer reaches the tap.

## 🎮 Controls

| Action | Keyboard | Touch / Mobile |
| :--- | :--- | :--- |
| **Move Up / Down Lane** | `Up Arrow` / `Down Arrow` | Tap target lane |
| **Run Along Bar** | `Left Arrow` / `Right Arrow` | — |
| **Pour / Serve Beer** | `Spacebar` (at right end) | Tap right side |
| **Start / Restart** | `Spacebar` / `Enter` | Tap screen |

---

## 🛠️ Technical Features

* **Pure HTML5 / Vanilla JS:** Zero external libraries, npm dependencies, or heavy game engines.
* **Web Audio API Synthesizer:** Fully code-generated retro sound effects (pouring, glass catches, crashes, tips) without external `.wav` or `.mp3` files.
* **Procedural Pixel Art & CRT Overlay:** Canvas 2D graphics styled after the original 1983 cabinet layout with custom scanline effects.
